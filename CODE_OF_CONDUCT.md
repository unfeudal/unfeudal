# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment, no personal attacks. Disagree about code, not about people.

To report unacceptable behaviour, write to **contact@killiandalcin.fr**. Reports are read only by the maintainers and kept confidential.
